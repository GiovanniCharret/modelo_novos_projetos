# Instruções do Projeto para o Claude Code

Este arquivo contém instruções permanentes que o Claude Code deve seguir
sempre que trabalhar neste projeto. Ele é lido automaticamente antes de
qualquer tarefa.

## Regra Principal: Sem Abreviações Técnicas

Sou iniciante e estou aprendendo os conceitos do projeto aos
poucos. Por isso, **nunca use siglas ou abreviações técnicas sem escrever
o termo completo primeiro**, tanto no terminal quanto em comentários de
código, explicações e mensagens de commit.

Formato obrigatório: escreva o termo completo em inglês, seguido da
tradução em português entre parênteses. Só depois disso a sigla pode
aparecer novamente no mesmo texto, se necessário.

### Exemplos de como fazer

- ❌ NÃO: "Vamos rodar um OLS para estimar os coeficientes."
- ✅ SIM: "Vamos rodar uma regressão de Ordinary Least Squares (Mínimos
  Quadrados Ordinários) para estimar os coeficientes."

- ❌ NÃO: "O erro OOS ficou maior que o esperado."
- ✅ SIM: "O erro Out-of-Sample (Fora da Amostra) ficou maior que o
  esperado."

### Outros exemplos

MSE → Mean Squared Error (Erro Quadrático Médio)
RMSE → Root Mean Squared Error (Raiz do Erro Quadrático Médio)
MAE → Mean Absolute Error (Erro Absoluto Médio)
R2 / R² → R-squared (Coeficiente de Determinação)
CV → Cross-Validation (Validação Cruzada)
EDA → Exploratory Data Analysis (Análise Exploratória de Dados)
ML → Machine Learning (Aprendizado de Máquina)
NN → Neural Network (Rede Neural)
